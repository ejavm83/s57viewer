S-57 전자해도 웹 뷰어

상세 설명서 — 일반인도 이해할 수 있도록 모든 개념을 풀어서 설명합니다.

1. 프로젝트 개요

이 프로젝트는 무엇인가요?

이 프로젝트는 대한민국 전자해도(Electronic Navigational Chart) 데이터를 웹 브라우저에서 볼 수 있는 지도 뷰어입니다.

전자해도란 종이 해도(바다 지도)를 디지털화한 것으로, 선박이 안전하게 항해하기 위해 필요한 모든 정보를 담고 있습니다. 바다의 깊이, 등대 위치, 부표(바다 위에 떠 있는 표지), 암초, 침몰 선박, 해안선 등의 정보가 포함됩니다.

S-57이란?

S-57은 국제수로기구(IHO)가 정한 전자해도의 국제 표준 데이터 형식입니다. 전 세계 대부분의 해양 국가가 이 형식으로 전자해도를 제작하며, 선박에 탑재되는 ECDIS(전자해도표시시스템)에서 사용됩니다.

S-57 파일은 일반적인 이미지 파일이 아니라 바이너리 형식의 구조화된 데이터로, 특수한 소프트웨어 없이는 내용을 볼 수 없습니다. 이 프로젝트는 이러한 S-57 데이터를 일반 웹 브라우저에서 시각적으로 볼 수 있게 변환하여 보여줍니다.

3. 백엔드 서버 상세

서버는 3가지 핵심 작업을 수행합니다:

1. S-57 파일 인덱싱

서버 시작 시 744개 파일을 스캔하여 각 파일이 어느 해역을 커버하는지, 어떤 축척인지, 어떤 정보가 들어있는지를 목록으로 만듭니다.

2. S-57 → GeoJSON 변환

브라우저가 요청하면 해당 해역의 S-57 파일을 읽어서 웹 지도에서 사용할 수 있는 GeoJSON 형식으로 변환합니다.

3. 웹 페이지 제공

HTML, CSS, JavaScript 파일을 브라우저에 전달합니다.

해도 축척(Scale) 체계

한국 전자해도 파일명의 3번째 글자가 축척 등급을 나타냅니다. 축척이란 지도에서 1cm가 실제 거리 몇 m에 해당하는지를 나타냅니다. 숫자가 작을수록 더 상세한 지도입니다.

수심 색상 체계

바다의 깊이에 따라 다른 색으로 표시됩니다:

0m 이하 (간출지) — 썰물 때 드러나는 곳
0 ~ 5m — 매우 얕음 (소형 선박 주의)
5 ~ 10m — 얕음
10 ~ 20m — 보통
20 ~ 50m — 깊음
50m 이상 — 매우 깊음

7. 성능 관련 참고사항

항목상세
최초 인덱싱744개 파일 스캔에 1~2분 소요 → 이후 캐시에서 즉시 로드
레이어 변환각 레이어 최초 요청 시 수초 소요 → 이후 캐시에서 즉시 응답
동시 로드 제한한 번에 최대 30개 해도까지 로드 (성능 보호)
브라우저 메모리수만 개 피처 로드 시 느려질 수 있음 → 불필요한 레이어 끄기 권장
캐시 초기화cache/ 폴더 삭제 후 재시작
