1. Project Overview

What Is This Project?

This project is a web map viewer for Republic of Korea Electronic Navigational Chart (ENC) data.

An ENC digitizes paper nautical charts. It contains depth, lights, buoys, rocks, wrecks, coastlines, and other information needed for safe navigation.

What Is S-57?

S-57 is the IHO international standard format for ENC data. Most maritime nations publish ENCs in this format for use in ECDIS (Electronic Chart Display and Information Systems).

S-57 files are structured binary data, not ordinary images. This project converts S-57 data so it can be viewed in a standard web browser.

Data Source

Select a folder containing S-57 .000 files in the viewer sidebar (server browse or browser upload), or set S57_DIR. After indexing, Folder analysis appears in the sidebar; use GET /api/datasource/report for full details.

Format

IHO S-57 ENC (.000)

Example dataset

KHOA ENC, 21 June 2024 (NTM-25) — ~744 files

Example coverage

Republic of Korea (Jeju, Dokdo, Ieodo)

Rendering

IHO S-52 PresLib e4.0.0 (DAY)

Warning: This viewer is for education and demonstration only. It must not be used for navigation.

3. Backend Server

The server performs three core tasks:

1. S-57 file indexing

On startup the server scans 744 files and builds a list of coverage, scale, and layer content for each chart.

2. S-57 → GeoJSON conversion

When the browser requests data, the server reads the relevant S-57 files and converts them to GeoJSON for the web map.

3. Serve web pages

Delivers HTML, CSS, and JavaScript to the browser.

Chart scale system

In Korean ENC file names, the third character is the scale band. Scale is the map ratio (e.g. 1:10,000). Smaller denominators mean more detail.

BandFilename patternApprox. scalePurposeExample
1KR1xxxxx1:3,500,000Ocean passage (broad coverage)KR1F0000.000
2KR2xxxxx1:700,000Coastal navigationKR2F2000.000
3KR3xxxxx1:180,000Approach navigationKR3F4G00.000
4KR4xxxxx1:90,000Coastal detailKR4F4G10.000
5KR5xxxxx1:22,000Harbour approachKR5F4G13.000

Data conversion pipeline

Steps from S-57 file to map display:

S-57 file (.000)

ISO 8211 binary format

↓ read with pyogrio
WKB geometry + attribute table

Binary coordinates and attributes

↓ WKB parsing (parse_wkb)
GeoJSON conversion

{"type":"Feature", "geometry":{"type":"Point", "coordinates":[129.05, 35.10]}, ...}

↓ save JSON cache under cache/
HTTP response → OpenLayers rendering

Visualized on the map in the browser

IHO S-52 Presentation Library (PresLib e4.0.0)

Map colours and symbols follow public/PresLib_e4.0.0.dai, parsed by scripts/build_preslib.py into static/s52-preslib.json and applied at runtime by s52-preslib.js.

ItemValue
Version / palette4.0.0, DAY
Colour tokens67 (CCIE xyY → sRGB)
Object classes151 S-57 objects
LUPT lookup rules1,164 (geometry + attribute + INST)

Each feature is matched to a LUPT rule; instructions (AC, LS, SY, CS) become OpenLayers styles. Conditional symbology includes DEPARE03, DEPCNT03, SOUNDG03, LIGHTS06, OBSTRN07, and WRECKS05.

Regenerate JSON: python scripts/build_preslib.py

Depth colour scheme (DEPARE03)

Depth areas use S-52 tokens from DRVAL1 and default contours (shallow 10 m, safety 30 m, deep 30 m):

DEPIT — drying (<0 m)
DEPVS — 0–10 m
DEPMS — 10–30 m
DEPMD — medium band
DEPDW — deep (≥30 m) / sea background

6. How to run

Requirements

SoftwareMinimum versionCheck install
Python3.10+python --version
pipLatestpip --version

Install and run

Install dependencies

pip install fastapi uvicorn pyogrio

Start server

cd "D:\src\s-57 viewer" then python server.py

Open in browser

Open http://localhost:8080

Note: First run indexes 744 files (about 1–2 minutes). Later runs use the cache and start immediately.
